# 🔧 Developer Portfolio – Auto-Annotated

This is my custom portfolio built with **Next.js** and **Tailwind CSS**, fully integrated with the **Netlify Visual Editor**. It supports inline editing using automatic component annotations—no need to manually sprinkle data attributes across the codebase.

🔍 Content is annotated dynamically in `src/utils/content.ts` and rendered via `src/components/components-registry.tsx`.

🚀 **Can be seen:** [online-page](https://joniroine.netlify.app/)
