I have completed the AWS Fundamentals Specialization on Coursera, which consists of three courses that provided me with a comprehensive understanding of Amazon Web Services (AWS). These courses covered the core features, benefits, and capabilities of AWS, including key security concepts and strategies for migrating from on-premises to the cloud.

Course 1: AWS Cloud Technical Essentials

Course 2: Migrating to the AWS Cloud

Course 3: Architecting Solutions on AWS

Throughout this specialization, I gained hands-on experience through labs and exercises developed by AWS technical instructors, which allowed me to apply what I learned in practical scenarios. This certification also introduced me to the basics of building serverless applications on AWS.

With this knowledge, I am equipped to design, migrate, and manage AWS-based solutions, ensuring performance, security, and scalability in cloud environments.
